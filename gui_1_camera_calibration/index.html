Video folders
each folder holds one video per camera. Any name containing a camera number works: cam1.mp4, cam_01.mov, camera_001.mp4 … → camera_001. Intrinsic videos should sweep the board across the whole image of ONE camera at a time; several intrinsic folders (sessions) are pooled per camera, which is valid as long as focus / aperture were not touched between them. Extrinsic videos must be recorded synchronously with the board visible to all cameras, from ONE session.

intrinsics only → <name>_intrinsics.json. Extrinsics / both → <name>.json + rig plots. "Run extrinsics" keeps the focal length / distortion from the intrinsics json fixed (unless "refine fx" is ticked) and solves the rig geometry; "Run both" calibrates intrinsics from the intrinsic folder(s) first. All reprojection errors are RMS per corner in px (target < 0.7 px after bundle adjustment).
